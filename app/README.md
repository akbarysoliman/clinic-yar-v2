# کلینیک‌یار — نرم‌افزار مدیریت کلینیک چندشعبه‌ای

## اجرای پروژه روی سیستم خودتان

نیازمندی: [Node.js](https://nodejs.org) نسخه ۱۸ به بالا نصب باشد، و بک‌اند (`clinic-api`) در حال اجرا باشد.

```bash
cp .env.example .env   # اگر آدرس بک‌اند شما با http://localhost:4000/api فرق دارد، تغییرش دهید
npm install
npm run dev
```

بعد از اجرا، آدرس نمایش‌داده‌شده در ترمینال (معمولاً `http://localhost:5173`) را در مرورگر باز کنید.

برای ساخت نسخه نهایی جهت انتشار روی هاست:

```bash
npm run build
```

خروجی در پوشه `dist/` قرار می‌گیرد که می‌توانید روی هر هاست استاتیک (مثل Vercel، Netlify یا سرور خودتان) آپلود کنید.

## وضعیت فعلی این نسخه

این نسخه به‌طور کامل به بک‌اند واقعی (`clinic-api`) وصل است — دیگر داده نمایشی (mock) وجود ندارد. تمام صفحات فاز ۱ پیاده‌سازی شده‌اند:

- ورود با شماره تماس/رمز
- نوبت‌دهی (با بررسی تداخل، بر اساس برنامه واقعی هر پزشک)
- صف امروز (تغییر وضعیت زنده: پذیرش → در حال ویزیت → تکمیل)
- تقویم پزشک + ثبت ویزیت مستقیم از روی نوبت
- «بیماران من» — تاریخچه کامل هر بیمار به‌همراه نسخه‌ها
- «نسخه‌نویسی» — ثبت ویزیت و نسخه بدون نیاز به نوبت قبلی (مثلاً برای مراجعه حضوری)
- «تسویه‌حساب» منشی — ثبت پرداخت نقدی/کارتی/بیمه و فهرست تسویه‌های روز
- داشبورد و فهرست شعبه‌های مدیر (با آمار واقعی)
- «گزارش مالی» مدیر — درآمد ۳۰ روز اخیر به تفکیک شعبه و روش پرداخت
- «تنظیمات» مدیر — فهرست و ساخت کاربران جدید (مدیر شعبه/پزشک/منشی/حسابدار)

برای اجرا، ابتدا باید `clinic-api` را طبق راهنمای خودش راه‌اندازی کرده و `npm run db:init` را زده باشید (کاربرهای آزمایشی برای **دو شعبه** می‌سازد تا سناریوی چندشعبه‌ای هم قابل تست باشد).

مواردی که هنوز باقی مانده:

| مورد | توضیح |
|---|---|
| مدیریت بیمه‌ها و تعرفه‌ها | فاز بعدی |
| پیامک یادآوری نوبت | نیازمند اتصال به یک سرویس پیامک (مثل کاوه‌نگار) |
| تست با کاربر واقعی | پایلوت در یک مطب واقعی و رفع اشکال |
| آماده‌سازی انتشار | دامنه، هاستینگ، مستندات، قیمت‌گذاری |

## ساختار پوشه‌ها

```
clinic-app/
├── src/
│   ├── App.jsx             پوسته اصلی برنامه (نقش‌ها، منوها، صفحات)
│   ├── DoctorScreens.jsx    صفحات «بیماران من» و «نسخه‌نویسی»
│   ├── SecretaryCheckout.jsx صفحه «تسویه‌حساب»
│   ├── AdminScreens.jsx      صفحات «گزارش مالی» و «تنظیمات» مدیر
│   ├── LoginScreen.jsx      صفحه ورود
│   ├── AuthContext.jsx      مدیریت وضعیت ورود
│   ├── api.js               کلاینت ارتباط با بک‌اند
│   ├── theme.jsx            رنگ‌ها و اجزای مشترک UI
│   ├── jalali.js            تبدیل تاریخ شمسی/میلادی
│   └── main.jsx             نقطه ورود React
├── database/
│   └── schema.sql        شِمای پایگاه‌داده (نسخه مرجع؛ نسخه اصلی در clinic-api است)
├── index.html
├── package.json
└── vite.config.js
```
